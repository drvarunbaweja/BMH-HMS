# Queue Display Media

This folder stores the images used by the hospital queue display pages.

Share this GitHub folder with anyone who needs to update the display photos:

`src/public/assets/queue-media/`

## How to update images

Replace an image with a better one using the same file name. The queue display will pick it up after the change is pushed and deployed.

Recommended format:

- JPG or PNG
- Landscape images for department education slides
- Full-height doctor photos for doctor profile slides
- Keep file size modest so TV browsers load quickly

## Queue Pages

- Main configurable page: `src/public/queue-display.html`
- Chandigarh page: `src/public/queue-display-chandigarh.html`
- Ropar page: `src/public/queue-display-ropar.html`
- Short Chandigarh shortcut: `src/public/chdbmh/index.html`
- Short Ropar shortcut: `src/public/rprbmh/index.html`
